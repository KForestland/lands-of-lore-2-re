# Historical LoL2 research helpers

> **Historical.** These tools are kept with their original research notes and fixture requirements. Some reproduce narrow earlier observations or test superseded interpretations. The main reader suite is listed in the [tools reference](../README.md).

The [cave geometry pipeline](draracle/run_geometry_pipeline.py) is retained with its pinned-input checks and companion scripts. Its synthetic tests run with `python3 -m unittest discover -s tools/history/draracle`. Run the pipeline using a matching original installation and an output directory outside the repository. [Cave geometry notes](../../docs/draracle-restoration.md)

The old entry-1 atlas experiment stays here with its supporting LCW-like reader. Use the current shape reader for the options entry and the texture container reader for level banks. [Entry-1 format](../../docs/formats/room-sections.md)
