# Repository Scope

> **History.** A note from an earlier pass, kept as a record. Current pages: [STATUS.md](STATUS.md) and [formats/](formats/README.md); where they differ, the current pages are right.

This repository documents the current reverse-engineering state of *Lands of Lore II* and publishes the cleaned closure notes needed to review the LoL2 reverse engineering.

Included:

- reverse-engineering pages
- evidence indexes and witness maps
- tool notes and workflow summaries
- future patch planning notes kept separate from canon

Excluded from the initial repo:

- raw retail game files
- full copyrighted asset dumps
- raw AI memo sprawl
- one-off scratch scripts that only served a single local test

The goal is the same standard used for the LoL1 repo:

- readable
- reviewable
- technically honest
- useful without turning the repo into a copyrighted asset mirror
