# What's new

Newest first. One line per question worked on, new tool or visible change; each question bullet gives its state. Details are on the linked pages; the counts are in the [rating](../README.md#rating).

## 20 November 2026

- **Moving items and props.** The level plans export moves of existing items and props inside their own regions, for a copy ([level editor](LEVEL_EDITOR.md)).
- **Intro skip (optional comfort patch).** Two jumps skip the opening Westwood card, the title and the intro movie; tried in the original game before and after on 20 November ([patches](../patches/README.md)).
- **Tavern crash not reproduced.** On the measured setup (DOSBox 0.74-3, `memsize=30`) the unpatched game entered the Huline tavern without the reported memory crash, so the published two-byte extender edit is recorded but not shipped ([patches](../patches/README.md)). The running page now names the movement keys: the arrow keys walk and turn ([running](../patches/RUNNING.md)).
- **Translation kit.** Export the game's text tables to CSV files in your own folder, translate them, build a copy and check that every character exists in the game's fonts ([translation](TRANSLATION.md)). The exported text stays private.
- **Patch format, version 3.** A shared patch now stores only the length and SHA-256 of each original span, never the original bytes; applying still refuses a mismatch, and undo uses the private `undo.json` written on your own machine, which holds original bytes and must not be shared ([patch format](formats/patch.md)). Older patches still apply.
- **Editions and unused material.** Which releases were measured, with sizes and SHA-256 fingerprints ([editions](EDITIONS.md)), and what is in the files but not reached, counted and described, not extracted ([unused](UNUSED.md)).
- **Python 3.10 or later.** One minimum for all three repositories; the automatic checks run Python 3.10 and 3.12 on Linux, Windows and macOS.
- **Tools for your own copy.** A mod kit changes text and numbers in a separate folder and checks the result; with it you can also open interactive level plans, convert movies and sounds. Start with the [first ten minutes](FIRST_TEN_MINUTES.md) page or `python3 tools/lol.py`.
- **Corrections.** A new page lists what these pages got wrong, how it was caught and the commit that fixed it ([corrections](CORRECTIONS.md)).
- **Checks on three systems.** The automatic checks now run on Linux, Windows and macOS; the size and index checks no longer depend on line endings.
- **Patches and save copies.** `patch.py` makes a small patch from a mod kit build, applies it to a copy of the game and writes an undo patch; program patches are checked against the program's SHA-256. `save_edit.py` changes one field in a copy of a save and prints the old and the new value. The [README](../README.md#change-a-number-in-your-own-copy) walks through one number from unpack to undo ([patch format](formats/patch.md), [cookbook](COOKBOOK.md#change-a-saved-game-a-copy)). `GLOBAL.MIX` ships twice and which copy the game opens is not known, so the README example changes both.
- **Running-game probes for Q13, Q10, Q5 and Q16 (states unchanged).** On an unedited level-8 save, four of the eight category cue words held their file values and were not read during a short stand and walk; that level does not load the room that calls them, so the known readers were not tested ([speech](lol2-speech.md#running-game-observation-in-l8_sj)). One creature with the player as target reached the mode-2 compare at `0xA32B4` with +0xB4 bit 0x20 set; the branch after it was not watched ([creature observation](lol2-creature-observation.md#live-entry-to-the-player-target-branch)). The shade-index probe was not run although two game-written L10_DC saves exist; the Huline Temple probe needs a save inside L14_HT ([probes](NEEDS_A_RUNNING_GAME.md#probes-not-yet-run)).
- **Running-game probes for Q9, Q12 and Q3 (all three stay mostly answered).** With a live memory edit, a lesson whose ID was removed from the learned list reached the message-0x23 push; the timer field for message 0x26 did not visibly change in a few seconds, which does not settle Q9 ([live edit](lol2-spell-dispatch.md#absent-id-lesson-branch-live-edit)). On the relocated level-20 copy, setting prop 87's state byte to 13 in memory did not start `bb_brth`, so frame 115 stays blocked ([edited saves](EDITED_SAVES.md)). Each load into L20_BB opened `l20_bb.MIX`, `l20_bbI.MIX` and `CDCACHE.MIX` through the archive constructor, and no ARENA open followed the opening movie ([room archives](lol2-room-archives.md#the-extra-arena-archive)).
- **Program entry.** LE `+0x1C` (file `+0x3BCD0`, `0C 7B 0F 00`) is the entry offset in object 2: code address `0x150B30`, a jump over the compiler's copyright text. `lol2_parse_le.py --check` pins it ([executable tables](lol2-executable-tables.md)).
- **Fault locations and running notes.** The patch page now places each report. The published two-byte edit for the tavern crash (`LOLG.EXE` `VirtualSize:24M` to `32M`) is recorded there with its bytes and was applied and undone on a copy; it ships as a patch file only after an in-game test. [Running the DOS game](../patches/RUNNING.md) lists the programs and the setup keys ([patches](../patches/README.md)).
- **Room imports and the save preview flag (Q13 stays partly answered, Q11 stays mostly answered).** The 47 room modules make 3134 absolute indirect calls, and each one resolves to one of 63 host functions. None of those functions, walked to every return, calls the text loader `0xCF014` directly; host +0xC4 reaches it four calls deep in the options menu `0xB9204`. 763 calls from 37 modules enter `0xEE784`. Host slot +0x13C is `0xF16D8` (31 calls): it indexes a cue word at `0x269CC` and calls the cleanup `0xE4004`. The slot header stores zero at +0x94 and the constant 1 at +0x98. +0x98 is the preview flag: the reader `0xE61F4` tests it at `0xE62D2` before it loads the preview. Four 0x25A-byte reads pass the header to the validator `0xEB82C`, and neither it nor the four reading functions address +0x94 ([speech](lol2-speech.md), [save witnesses](lol2-save-field-witnesses.md)).
- **Resource flag and the slot-37 bit (Q1 and Q6 stay mostly answered).** The 66 relocated references to data `0x223D6` are reads: 38 compares with 0 and 28 byte loads. None stores the byte or loads its address, and no word or dword access covers it, so it keeps its zero start (it lies past the stored data) and the texture name on that path is `global\global.tex`; a store through a register pointer was not ruled out. Four other row-builder calls push a packed length of zero. One call, at `0x9DE84`, can still reach the decoder from a name built before the call at `0x9C3E8` by appending the suffix at cell `0xBFF` (`.tex`). The gate at `0xD01C5` copies player +0x229 and does not read +0x228. The arm that sets player +0x228 bit `0x80` and the six routines it calls directly do not read that byte; the clear at `0xD7B21` is the sibling subcommand-`0x27` arm, and the eight tests of the bit lie below `0xD7ABC` ([compression](formats/compression.md), [shared predicates](lol2-shared-predicates.md)).
- **Status gaps closed from the files.** `lol2_parse_le.py --check` (now in `check_all.py`, 46 checks) reads the LE header, five objects, all 340 page-map rows and the fixup boundaries of `LOLG.DAT` ([executable tables](lol2-executable-tables.md)). `lol2_texture_container.py --check` walks all 30,597 row-span mips to their last byte and partitions the 27,889 `0x1246` frame descriptors into 1,844 groups ([creature frame groups](creature-frame-groups.md)); a `rows` command lists one mip's row headers. `lol2_vqa_v2_decode.py --check` pins the command extents of the two exceptional movie packets; frame 492's ends after 1,059 of 32,000 bytes. Open: which pixels that frame shows (Q12) ([VQA](formats/vqa.md#structure-of-the-two-exceptional-packets)).
- **XMIDI scores.** The 33 `FORM` members of `LOCAL.MIX` are XMIDI scores: their keys are the MIX hashes of `MUSIC\<stem>.XMI` for the same stems the HMI songs use, plus CREDITS. `tools/lol2_xmi_reader.py --check` walks every IFF chunk and event: 33 sequences, 559 TIMB pairs, 109,623 events. Open: which build or configuration plays them ([XMIDI](formats/xmi.md)). `check_all.py` now runs 45 checks.
- **Checks tested against planted mistakes.** Twenty deliberate wrong changes per repository were made in scratch copies; the checks caught 19 of 20 after they were strengthened. The one left is a wording change that keeps every byte, table and link valid, so only a reader comparing the sentence with its evidence can catch it ([check audit](CHECK_AUDIT.md)). `check_all.py` prints each check's time and the total, and `--quick` skips the slowest checks and lists them; the full run stays the default.
- **Confirmed statements re-derived.** Two samples of 30 statements each were re-derived from the bytes; 60 different statements in all. Every wrong or overstated one was corrected on its page ([sample](CONFIRMED_SAMPLE.md)).
- **Header bytes.** `LOLG.DAT` at file +0x3BCC4 is `00 02 00 00`. `lol2_cache_seed.py --check` re-reads those four bytes and does not interpret them ([executable tables](lol2-executable-tables.md)).

## 19 November 2026

- **Header bytes.** `LOLG.DAT` at file +0x3BCCC is `02 00 00 00`. `lol2_cache_seed.py --check` re-reads those four bytes and does not interpret them ([executable tables](lol2-executable-tables.md)).
- **Music writer.** `tools/lol2_hmi_writer.py --check` rebuilds all 33 HMI songs in `LOCAL.MIX` (438 tracks) byte for byte from their parsed events; the track directory is regenerated, the song and track headers are copied ([round trip](ROUND_TRIP.md#music-hmi)). `check_all.py` now runs 43 checks.
- **Level script and text writers.** `tools/lol2_level_writer.py --check` rebuilds the command streams, event pools and predicate rows of all 15 level MIXes from parsed fields, and each archive equals the original; only these sections (0.34 % of the bytes) are rebuilt, the geometry, textures and other members are copied. `tools/lol2_text_writer.py --check` rebuilds all eight retail TRR message tables byte for byte ([round trip](ROUND_TRIP.md)). `check_all.py` now runs 42 checks.
- **Instance byte +5 and script arms (Q8 and Q4, both mostly answered).** Sixteen readers and writers of the placed-item byte at record +5 are listed: fifteen of 162 byte accesses at displacement 5 that the scan reaches, and one store at object +0x31. Only handler 102 stores 5; opcode 2 selectors 0 and 38 and `0xDD584` store 0 again. Opcode 2 has a handler for each selector 0 through 66. The jump tables of opcodes 6, 9 and 15 have 13, 35 and 113 slots with 13, 31 and 69 different targets. Open: what the byte means in play, and the on-screen result of an arm that only calls onward ([instance byte](lol2-item-handlers.md#instance-byte-5), [subcommand handlers](lol2-script-opcodes.md#subcommand-handlers)). `lol2_instance_field.py --check` requires both tables. `check_all.py` now runs 40 checks.
- **How a level is put together.** The pieces a level needs, the file that holds each and the order the program loads them ([level assembly](HOW_A_LEVEL_IS_PUT_TOGETHER.md)).
- **Tour.** One level followed end to end: its picture, sheet, exits and numbers, with the command behind each part ([tour](TOUR.md)).
- **Across the three games.** How each game gates progress and scales its numbers, each fact linked to its evidence ([progress and numbers](series-progress-and-numbers.md)).
- **Page index.** `docs/index.json` lists every page, the questions it answers and the tools it cites; `tools/doc_index.py --check` keeps it current ([index](index.json)).
- **Round trip.** What each writer proves: which containers rebuild byte for byte and which data only decodes identically ([round trip](ROUND_TRIP.md)).
- **Tool options.** One name for the data folder, the check and the output in every tool; old spellings still work as aliases ([tools](../tools/README.md)).
- **LZ77 encoder and save writer.** `tools/lol2_westwood_writer.py` encodes Westwood LZ77 in both offset modes; `--check` re-encodes the 37 compressed `options.shp` shapes, the 640 WSA panel deltas and the 15 `global.tex` texture streams and re-reads each with the same decoded bytes. The compressed bytes differ from the originals (decode-identical, not byte-identical), and all these original streams use the absolute mode. `tools/lol2_save_writer.py --check` rebuilds the game-written saves in `SAVEGAME` byte for byte from parsed fields and stored chunks (30 saves and 154 level blocks in the working installation, 27 and 149 in the reference copy); headers and directories are regenerated, the LZO chunks are copied as stored, so this shows the save layout, not the compressor. `check_all.py` now runs 39 checks.
- **MIX writer.** `tools/lol2_mix_writer.py` writes a MIX archive from its rows; `--check` rebuilds all 81 `DAT/` archives and the 6 shipped game-folder archives in memory, byte-identical (3,463 rows). The data has no vacant bytes and in 82 archives the payloads are not in row order; `CDCACHE.MIX` is skipped because the game writes it ([MIX writing](formats/mix.md#writing)). `check_all.py` now runs 37 checks.
- **Plot branches outside the exits (Q6, mostly answered).** The 15 level archives hold 289 events that test a shared plot byte and are not one of the 72 exits: 287 groups, 28 shared slots, and none in L7_DH. Each row gives the record and the fields its matcher reads, the predicate and every command in the linked group; 16 rows are marked as 0/1 selectors. `lol2_plot_branches.py --check` requires the table on the shared-predicates page to match. Open: whether each branch is reached, and the on-screen result ([shared predicates](lol2-shared-predicates.md#shared-predicates-outside-exits)). `check_all.py` now runs 36 checks.
