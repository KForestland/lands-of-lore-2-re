# What's new

Newest first. One line per question worked on, new tool or visible change; each question bullet gives its state. Details are on the linked pages; the counts are in the [rating](../README.md#rating).

## 19 November 2026

- **How a level is put together.** The pieces a level needs, the file that holds each and the order the program loads them ([level assembly](HOW_A_LEVEL_IS_PUT_TOGETHER.md)).
- **Tour.** One level followed end to end: its picture, sheet, exits and numbers, with the command behind each part ([tour](TOUR.md)).
- **Across the three games.** How each game gates progress and scales its numbers, each fact linked to its evidence ([progress and numbers](series-progress-and-numbers.md)).
- **Page index.** `docs/index.json` lists every page, the questions it answers and the tools it cites; `tools/doc_index.py --check` keeps it current ([index](index.json)).
- **Round trip.** What each writer proves: which containers rebuild byte for byte and which data only decodes identically ([round trip](ROUND_TRIP.md)).
- **Tool options.** One name for the data folder, the check and the output in every tool; old spellings still work as aliases ([tools](../tools/README.md)).
- **LZ77 encoder and save writer.** `tools/lol2_westwood_writer.py` encodes Westwood LZ77 in both offset modes; `--check` re-encodes the 37 compressed `options.shp` shapes, the 640 WSA panel deltas and the 15 `global.tex` texture streams and re-reads each with the same decoded bytes. The compressed bytes differ from the originals (decode-identical, not byte-identical), and all these original streams use the absolute mode. `tools/lol2_save_writer.py --check` rebuilds the game-written saves in `SAVEGAME` byte for byte from parsed fields and stored chunks (30 saves and 154 level blocks in the working installation, 27 and 149 in the reference copy); headers and directories are regenerated, the LZO chunks are copied as stored, so this shows the save layout, not the compressor. `check_all.py` now runs 39 checks.
- **MIX writer.** `tools/lol2_mix_writer.py` writes a MIX archive from its rows; `--check` rebuilds all 81 `DAT/` archives and the 6 shipped game-folder archives in memory, byte-identical (3,463 rows). The data has no vacant bytes and in 82 archives the payloads are not in row order; `CDCACHE.MIX` is skipped because the game writes it ([MIX writing](formats/mix.md#writing)). `check_all.py` now runs 37 checks.
- **Plot branches outside the exits (Q6, mostly answered).** The 15 level archives hold 289 events that test a shared plot byte and are not one of the 72 exits: 287 groups, 28 shared slots, and none in L7_DH. Each row gives the record and the fields its matcher reads, the predicate and every command in the linked group; 16 rows are marked as 0/1 selectors. `lol2_plot_branches.py --check` requires the table on the shared-predicates page to match. Open: whether each branch is reached, and the on-screen result ([shared predicates](lol2-shared-predicates.md#shared-predicates-outside-exits)). `check_all.py` now runs 36 checks.
- **Header bytes.** `LOLG.DAT` at file +0x3BCBC is `02 00 01 00`, eight bytes after the LE signature. `lol2_cache_seed.py --check` re-reads those four bytes and does not interpret them ([executable tables](lol2-executable-tables.md)).
- **Progression.** The 15 level archives hold 72 exit commands, 24 of them with a predicate over a shared slot, a local slot or the bound object's byte at +0x25. `lol2_progression.py --check` requires [progression](PROGRESSION.md) to equal that table. `check_all.py` now runs 34 checks.
- **Numbers at a glance.** `tools/lol2_numbers.py` generates tables of the 170 item combat inputs, the 113 effect records (64 costed levels in schools 0–12, 49 zero-cost records in rows 13–14), the 128 creature definitions and the 165 stored form requests. Five more actions (0x3C, 0x3D, 0x3F, 0x40, 0x41) enter the form arms and leave the command in place. `check_all.py` now runs 33 checks ([numbers](NUMBERS.md)).
- **Extender notice.** `LOLG.DAT` at file +0x25C begins `DOS/4G  Copyright`. `lol2_cache_seed.py --check` re-reads those seventeen bytes ([executable tables](lol2-executable-tables.md)).
- **Cross-series check.** The shared format pages already stated the same archive, movie, music and cache figures as the current notes, and the name-hash note now states the shift of 6 ([engine](engine-evolution.md)). The shared glossary words are the same text in each game ([glossary](GLOSSARY.md)).
- **Settling tests.** Five open statements now name the comparison or the follow that would settle them: nonpositive combat flags, the spell-school count byte, the effect 32/33 packet, the `0x02AC` mip path, and the short-block dword `0xFF00FFFF` ([combat](lol2-combat-ai.md), [tables](lol2-executable-tables.md), [spells](lol2-spell-dispatch.md), [textures](lol2-level-texture-container.md), [saves](lol2-save-format.md)). The combat, `0x02AC` and short-block tests are listed under [probes not yet run](NEEDS_A_RUNNING_GAME.md#probes-not-yet-run).
- **Close-out.** Fifteen open questions (Q1, Q3, Q4, Q5, Q6, Q8, Q9, Q10, Q11, Q12, Q13, Q14, Q16, Q17, Q20) each end with what was measured, what was tried, and what would settle the rest. States stay as they are ([open questions](OPEN_QUESTIONS.md)).
- **Program bytes.** `LOLG.DAT` at file +0x100 is `bd 01 68 0c df 07 91 0f df 07 95 0f df 07 89 10` ([executable tables](lol2-executable-tables.md)).
- **Resource names, seed sizes and cue loads (Q1 mostly, Q13 partly, Q20 mostly).** The byte at data `0x223D6` selects `global\global.tex` or `c:\leved\-global.tex`, and the same byte selects the sounds file ([compression](formats/compression.md), [sound cues](lol2-sound-cues.md)). The executable holds the version and date strings DOS 1.30, Dec 03 1997 17:51:02 (the VQA library inside it says Sep 05 1997). Each texture bank's first block names an art folder and a leved folder under `PROJECTS\LOL_2`; the seed still has no date, so the twelve older sizes stay open ([cache seed](lol2-cache-initializer.md)). Of the 533 direct uses of the cue table, 499 call the sound player, 11 the cleanup call and 21 compare the cue with a voice; one tests the pointer and one clears it ([speech](lol2-speech.md)).
- **Opcode and predicate re-read.** Opcode 11, opcode 205 and predicate operand types 1 and 6 were checked at the addresses those pages cite. The 15 level archives do not use them, and the program paths that would build a use do not. Three statements on those pages are closed ([script opcodes](lol2-script-opcodes.md), [predicates](lol2-script-events.md)).
- **Edited saves (Q12 and Q17, both mostly answered).** Three runs loaded a copy of a game-written save with a few bytes changed by hand. One added item 139 and played the `ss-4e` movie up to the odd frame 492, whose short copy read five zero bytes. One moved the party beside the `bb_brth` movie's prop, but that scene had already played (blocked). Two copies placed the party beside the level-8 controls 69 and 114, and empty-hand clicks reached both. [Edited saves](EDITED_SAVES.md) lists what each showed and what a game-written save would still add; the editing rules are on the [save page](lol2-save-format.md#editing-a-copy-of-an-original-slot). Open: frame 492's codebook and final picture and all of frame 115 (Q12), and the same clicks from a save reached in ordinary play (Q17).
- **Rating.** The running-game line now also says how many answered probes rest on edited saves only; today none do ([how we rate](HOW_WE_RATE.md)).
- **First countdown after a load or a menu pause (Q7, answered).** In the original game, the first countdown after loading a save used the restored whole ticks, and after the normal menu it used the retained ones ([timer](lol2-timer-clock.md#first-countdown-after-save-load-and-menu-pause)).
- **Placed-item click (Q18, answered).** An empty-hand left click on an original placed item in the first level reached its script group in the original game ([event producers](lol2-event-producers.md#empty-hand-left-click-on-l1_dc-placement-16)).
- **Opening-cave pickup (Q11, mostly answered).** Picking up an original loose item changed the expected save rows, compared with the save inspector. Open: some header fields and payload meanings ([save sections](lol2-save-sections.md#original-opening-cave-pickup-in-l1_dc)).
- **Lesson and timer control (Q9, mostly answered).** In the original game, a level-20 cast and an already-known lesson both left the timer field at zero. Open: which action arms the timer for message 0x26 ([spell dispatch](lol2-spell-dispatch.md#controlled-use-of-the-level-20-lesson)).
- **Saved animation rows (Q11, mostly answered).** The save writer and restore show where the level-26 surface rows and level-27 texture animation rows come from and which frame they keep ([save field witnesses](lol2-save-field-witnesses.md)).
- **Cookbook.** The [cookbook](COOKBOOK.md) gives short recipes on your own game files, each with its command and the first lines it prints.
- **Tools at a glance.** The README lists what you can look at with your own game files, one line and one command each ([tools at a glance](../README.md#tools-at-a-glance)).
- **Save inspector.** `lol2_save_inspect.py` prints the header, directories and named sections of a save you made, and one row of a section on request ([tools](../tools/README.md#lol2_save_inspectpy)).
- **Level schematic.** `lol2_level_schematic.py` draws a level from its original geometry, with items and creatures ([tools](../tools/README.md#lol2_level_schematicpy)).
- **Event browser.** `lol2_event_browser.py` lists one level's event groups and triggers and what they do ([tools](../tools/README.md#lol2_event_browserpy)).
- **Inspector views.** `lol2_inspect.py` prints an item definition, an animation, a spoken cue, a table inside the game program or the rules behind a topic ([tools](../tools/README.md#lol2_inspectpy)).
- **Parity table.** [tools/README](../tools/README.md#format-and-rules-coverage) lists every format and rules table with its reader, its check and what a reader prints.
- **Level sheets.** `lol2_level_report.py --check` requires each sheet under [levels](levels/README.md) to equal the text the tool writes. The fifteen sheets already match.
- **Glossary.** The [glossary](GLOSSARY.md) gives a one-line meaning to each term on the front page, the start page and the cookbook. A word shared with the other two games has the same meaning there. The rating still counts the glossary as a page, but not its label words.
- **Link check.** `doc_links.py` resolves every relative link and anchor in the README and the docs, and `check_all.py` runs it.
- **Files read to the last byte.** `lol2_loose.py` walks `AUTOPLAY.WAV` and `SETUP.EXE`, the two `DAT` files that are not MIX archives. The 41,584-byte DOS part of `SETUP.EXE` is counted by its length, not read ([loose files](formats/loose.md)).
- **Counted rating.** The README and [STATUS](STATUS.md) show four counted lines instead of a percentage; [how we rate](HOW_WE_RATE.md) explains them.
- **Interface shapes (Q2, answered).** The `LOCAL.MIX` entry once read as room data is `options.shp`, the options-screen pictures ([shape format](formats/room-sections.md)).
- **Credits music (Q15, answered).** The last unnamed music key is `MUSIC\CREDITS.HMI`.
- **Compression (Q1, mostly answered).** Every place the program unpacks LZ77 data is identified, with its buffers ([compression](formats/compression.md)). The original file names for the generic loaders remain open.
- **Scripts and levels (Q4, Q5, Q6, all mostly answered; Q18 answered).** Every level exit and its condition is listed, and every script group now has a known way in. The Q18 input gesture was then confirmed in play (see **Placed-item click** above). Open: Q6 plot branches outside the 72 exits, and some Q4 receivers and Q5 callers.
- **Items and spells (Q8, Q9, both mostly answered).** The items that become "burnt" or "empty" after use are named through the program's own label table, and each kind of thrown or fired object's hit is traced ([items](lol2-item-handlers.md), [spells](lol2-spell-dispatch.md)). Open: what instance +5 means in play (Q8) and what starts timed message 0x26 (Q9).
- **Timers and saves (Q7 answered, Q11 mostly answered).** How a save restores the game clock and how the menu pauses it; a table of every save section's reader and writer. The first countdown after resume (Q7) was then measured in the original game (see **First countdown** above); some save header fields (Q11) remain open.
- **Textures, walls and movies (Q12, Q14, Q16, Q20, all mostly answered).** Texture rows, wall spans with a replay of the original routine, movie pointer streams, and the shipped cache seed file. Open: two exceptional movie frames (Q12), the live `0x02AC` wall branch (Q14), the Huline Temple quads on screen (Q16) and which build supplied the 12 differing seed sizes (Q20).
- **Level-8 controls (Q17, mostly answered).** The two controls are joined to their geometry and the input path; the edited-save runs (see **Edited saves** above) then reached both by clicks. The same clicks from a save reached in ordinary play remain open.
- **Pictures.** Two unreadable example images were removed; the level map is regenerated and compared by its check.
- **New checks:** `rating.py`, `example_images.py`, `lol2_item_labels.py`, `lol2_save_native.py`, `lol2_cache_seed.py`, and a Huline wall replay check.
