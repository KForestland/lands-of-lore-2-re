# Level sheets

One sheet per level archive, written by `tools/lol2_level_report.py --data DAT --out docs/levels` from the original files only: entry roles, object counts, script statistics, exits and entity records. Ids and counts only; no game text. Every number on a sheet is regenerated by the tool.

Sections of a sheet:

- **Archive entries**: every MIX entry with its key, file offset and size, and what it is when known: the level data entry (found by its header), the texture container (found by the hash of its name) and the entry that holds the 147-byte entity records.
- **Geometry and objects**: table counts from the level data header.
- **Scripts**: the two command streams framed with the native size table; how often each opcode occurs.
- **Exits**: the level-transition commands and the objects whose events name their group.
- **Entity records** and the **companion archive** `L<n>_<xx>I.MIX` (sounds and movies).
