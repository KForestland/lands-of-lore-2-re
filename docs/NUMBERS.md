## Form requests

**CONFIRMED.** The compare tree at `0xD84DF` sends ten actions into five form arms. Each arm starts with `mov edi, 1`. Actions 0x04, 0x13, 0x15, 0x16 and 0x17 enter at that instruction and set +4 to 0xFF after the request. Actions 0x3C, 0x3D, 0x3F, 0x40 and 0x41 enter five bytes later with `edi` 0 and leave +4 unchanged. Every arm first tests actor +0x228 bit 0x10. The arms for 0x15–0x17 and 0x3F–0x41 skip the request when form +0x1AB already equals the pushed form.
